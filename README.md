# Online Art Gallery Management System

A Java-based web application developed for managing artworks, artists, customer registrations, and artwork purchases in an online gallery environment.

## Features

- User Registration and Login
- Artwork Management
- Artist Management
- Artwork Browsing
- Order Management
- Customer Authentication
- CRUD Operations
- Database Integration using MySQL
- Responsive Frontend Integration

## Technologies Used

- Java
- Spring Boot
- JDBC
- MySQL
- HTML
- CSS
- JavaScript
- React.js
- Docker

## Project Modules

### Admin Module
- Add artworks
- Update artwork details
- Delete artworks
- Manage artist records
- View customer orders

### User Module
- User registration and login
- Browse available artworks
- View artwork details
- Purchase artworks

### Order Module
- Order placement
- Order tracking
- Purchase history management

## Database

The application uses MySQL for storing:

- Artwork details
- Artist information
- User data
- Orders and transactions

## Key Concepts Used

- Object-Oriented Programming (OOP)
- REST APIs
- CRUD Operations
- JDBC Connectivity
- Backend Development
- Database Management
- MVC Architecture

## How to Run

### Clone Repository

```bash
git clone https://github.com/your-username/your-repository-name.git
```

### Configure Database

- Create MySQL database
- Update application.properties with database credentials

### Run Backend

```bash
mvn spring-boot:run
```

### Run Frontend

```bash
npm install
npm start
```

### Docker Setup

```bash
docker-compose up
```
